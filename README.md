# Schulart Ontology  

This repository contains the **Schulart Ontology** — an RDF/OWL-based ontology defining school types (“Schularten”) in the German school system.

## Overview  

The ontology provides a formal, machine-processible vocabulary for describing different **types of schools** (Schularten) such as Grundschule, Gymnasium, Realschule, Hauptschule, Gesamtschule, Berufsschule, etc.  
They are connected to the level/standard of a given educational track (Bildungsgangniveaus), reflecting the required depth and demand of learning outcomes across different types of schools and tracks.  

It is intended for use in semantic web, linked data and curriculum metadata contexts — enabling interoperable representations of school systems, curricula, and educational standards.
